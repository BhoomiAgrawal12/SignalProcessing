rf-analyzer

Automated blind analysis of .IQ / .WAV SDR recordings

rf-analyzer takes an unknown IQ or WAV recording and works its way from raw RF samples to an analyst-readable interpretation: signal detection, parameter estimation, modulation classification, demodulation, and a Bit-Layer Reconstruction Engine that blindly identifies scramblers, interleavers, forward error correction, frame structure, CRCs and payloads using GF(2) rank analysis.

S0-S2 Front end

WAV/RIFF parsing with the SDR auxi chunk, automatic raw-IQ format sniffing, conditioning, CFAR detection on the waterfall. The sample rate of a headerless file is reported unknown, never guessed.

S3-S5 Measurement

Channelisation, ITU occupied bandwidth, M2M4 SNR, cyclostationary symbol rate, FSK tone histograms, and a two-engine modulation classifier (higher-order cumulants + CVNet-RF) with an honest fusion voter that surfaces disagreement.

S6-S7 Demodulation

Feedforward Oerder&Meyr timing recovery, decision-directed carrier tracking, soft-bit LLR output, and a full phase/IQ/polarity ambiguity fan-out, because blind analysis is a search, not a pipeline.

S8-S10 Bit layer

Blind de-interleaving and blind FEC identification via bit-packed GF(2) rank deficiency, scrambler phase alignment, dual-code convolutional identification, Reed-Solomon syndrome sweeps, frame period detection, entropy field maps and CRC hunting.

S11 Reporting

JSON, CSV, SigMF annotations, PDF parameter sheet, payload export and a pre-configured GNU Radio flowgraph. Every number carries a confidence and the method that produced it.

Honest by design

Encrypted payloads are reported as high-entropy, not "decoded". Unknown modulations are reported unknown. The tool distinguishes detected, estimated, inferred, classified and validated.

Workflow

recording (.iq / .wav)
  -> format sniffing -> conditioning -> CFAR detection -> channelisation
  -> parameter estimation -> modulation classification -> demodulation
  -> ambiguity fan-out -> descrambling -> blind de-interleaving
  -> blind FEC identification -> framing -> CRC -> payload
  -> analyst report (JSON / CSV / PDF / SigMF / GRC)

The desktop application (PyQt6) and the CLI share one analysis engine. This site additionally runs the front half of that pipeline (S0-S5: ingestion, format sniffing, conditioning, detection, parameter estimation, modulation classification) directly in your browser on an uploaded .wav or .iq file, and provides a viewer for full reports exported by the desktop tool. The bit layer (blind de-interleaving, FEC identification, CRC hunting) needs the full search engine and runs in the desktop application.
